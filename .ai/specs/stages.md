
  Stage 1: Code API Specification — Done. The spec at .ai/specs/stage1-code-api-spec-v2.md covers all the conventions,
  attributes, directory structure, and patterns for the public code API.

  Stage 2: Supporting Code Specification — This is the next stage. It would cover:
  - The build script (src/Internal/Api/Scripts/): exactly what it does, how it scans src/Api/, what reflection/parsing
  it performs, and what it outputs
  - The autogenerated code (src/Internal/Api/Autogenerated/): the exact structure of generated GraphQL type classes,
  query/mutation wrappers, RootQueryType.php, RootMutationType.php
  - The fixed infrastructure (src/Internal/Api/): GraphQLController.php (endpoint handler, auth, error formatting),
  Main.php (initialization, staleness check, schema loading)
  - The staleness check mechanism (api_generation_date.txt)
  - Template files used by the build script

  Stage 3: Build Process Specification — When/how the build script runs (pnpm command, CI integration).

  Stage 4: Actual Implementation — Generate real code API classes for a selected part of WooCommerce (e.g., Orders).
